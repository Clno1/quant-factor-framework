# EP 字段关联审查：离线回归

后续已新增限定 EPS 正文的完整观察单元原型与实际 prompt 导出，见
[观察单元报告](ep_observation_units_20260910.md)。本文保留关联检查这一阶段的边界和统计。

## 到底是谁的问题

这次不是 API 连不通，也不是数字抄写失败，而是两个层面的问题叠加。

1. **模型确实选错了字段。** PLAB 的本期非 GAAP EPS 是 `$0.50`，模型却选中比较句里的 `third quarter` / `of 2025` 作为期间。那段去年的 EPS 是 `$0.51`。ANF 则把 `pre-tax basis` 当成 GAAP 的证据，并给退税总额附上了稀释每股属性。
2. **旧校验器的能力不够。** 它能确认 `$0.50`、`of 2025` 都在原文里，却不能确认这两个片段属于同一个财务观察值。它虽然保留了 `financial_semantics_verified=false` 和待审标志，但仅靠文字校验不足以支撑自动 EP 分析。这个缺口在程序的校验设计，不应全部归咎于模型。

模型是事实提案者，程序必须负责阻止证据不足或关系不匹配的提案继续进入评级。
换更贵模型可能改变错误率，但不能替代这层检查；本轮不需要新密钥、换模型或付费请求。

## 具体检查

| 检查 | 明确阻止 | 保留待核查的情况 |
| --- | --- | --- |
| 期间与数值 | 同一段里，期间和数值位于显式 `compared with/to`、`versus/vs`、`whereas` 比较结构的不同分句；比较列表中后续金额也单独检查 | 跨段期间、缺失期间、普通句子和表格中未证明的归属 |
| 主体 | 不把缺少主体或跨比较分句的主体当成已经核准 | 缺失主体、跨段/跨分句主体、发行人身份和 `ISSUER/SEGMENT` 归属始终待核查 |
| 会计口径 | 声明 GAAP/非 GAAP 但缺失或不匹配相应文字；只选择 `Non-GAAP` 中的 `GAAP` 子串 | 未知口径、口径是否可跨分句继承 |
| 单位与数量级 | 把 `$100 million` 或 `$1.75 per diluted share` 整体当成单位；不支持的单位/数量级片段 | `$` 的币种身份、跨表头数量级适用范围不自动推断 |
| 每股与总额 | 声明稀释/基本每股却缺少对应证据；带 million 等数量级的总额没有对应每股说明却赋予每股属性 | 明确写出带数量级的每股金额保留审查，不仅凭数量级判错 |

比较分句检查是**有限的确定性规则**，不是通用自然语言财务解析器。
普通 `and $金额` 不自动当成历史比较项；同一个比较分句中仍可能出现多个数值、主体或期间。
跨分句主体、币种和会计口径可能是合法继承，因此只标为未解决，不一律声称矛盾。
期间跨比较分句的选择会被阻止继续使用，但仍需要人工确认其真实关系，不能据此推断公告本身有误。

检查结果分两层：`text_validation_status` 保留旧文字结果，`status` 表示本轮关联审查结果。
存在文字拒绝或关联冲突时为 `BLOCKED`；其余为 `REVIEW_REQUIRED`。
**本轮没有引入自动 `VERIFIED` 状态，所有输出仍禁止评级和发送。**

## 真实模型回归结果

回归输入直接来自上轮三次 Kimi 实际响应，不是人工修正后的选择。
生成 fixture 时，用此前只读导出的完整请求重建选择目录，并验证：

- 目录包摘要与上轮预检 `packet_hash` 完全相同。
- 原始模型响应离线重放与上轮归档文字校验结果完全相同。
- fixture 只包含相关段落、原始响应和审计标识，不含密钥。

| 提案 | 旧文字结果 | 新关联结果 | 主要原因 |
| --- | --- | --- | --- |
| GTLB 本期营收 | 拒绝 | BLOCKED | GAAP 声明无口径片段，主体缺失、跨表头关联未解决 |
| GTLB 去年营收 | 拒绝 | BLOCKED | 同上；不是因为它是历史数据才拒绝 |
| ANF 退税 `$100 million` | 拒绝 | BLOCKED | 税前不等于 GAAP；整笔金额当单位；总额误用每股属性 |
| ANF 每股影响 `$1.75` | 拒绝 | BLOCKED | 税前不等于 GAAP；整段每股金额当单位；主体缺失 |
| PLAB GAAP EPS `$0.49` | 文字接纳 | REVIEW_REQUIRED | 未发现本轮规则定义的冲突，但跨段期间、主体语义尚未认证 |
| PLAB 非 GAAP EPS `$0.50` | 文字接纳 | BLOCKED | 期间选到比较分句的 2025 年，与本期数值不在同一观察分句 |

合计 **5 条阻止、1 条待核查、0 条自动核准**。
这不是模型准确率，也不是全文召回率；原文段落范围仍由人工限定。
上轮的历史结果保持原样，新报告将它嵌在 `text_validation` 中以便对照。
