## 固定试验入口

`reviews/2026-09-09-ep-llm-trial/run.py` 提供四个手动命令：

| 命令 | 作用 |
|---|---|
| `configure-key` | 交互隐藏输入密钥，默认写入 `/etc/quant/ep-llm-trial.key`，权限 0600；不覆盖已有文件、不连接模型 |
| `plan` | 检查四份固定原文、输入覆盖率和预算；不读取密钥 |
| `status` | 读取累计预留和调用状态 |
| `run GTLB --execute` | 仅执行指定的一份公告；必须显式确认，其他允许股票为 ANF/NYAX/PLAB |

入口固定模型和预算，不服从环境变量中的其他模型或更大预算。只使用独立试验数据库，不自动创建新库规避已花额度。重复请求、失败、崩溃保留的请求均不自动重试；异常计费需人工核对。

密钥只在用户的 SSH 终端隐藏输入，不贴聊天、不放命令参数。读取时拒绝符号链接、非当前用户所有或权限非 0600 的文件。配置密钥不会开启定时任务或触发任何模型调用。

用户可在自己的终端执行以下命令，出现隐藏输入提示后粘贴 API 密钥并回车：

```sh
ssh -t root@43.156.89.232 '/home/projects/quant/.venv/bin/python /home/projects/quant/tmp/ep-llm-trial-20260909/reviews/2026-09-09-ep-llm-trial/run.py --provider openai configure-key'
```

成功时只显示 `key_configured: true` 和文件位置，不显示密钥。配置完成后告知助手，再由助手按已批准的模型与累计预算先执行 GTLB 一份并核查输出。

## 验收顺序

先跑 GTLB 一份并人工核查，不一次性批量发送四份。接口拒绝 Schema、输出截断、计费异常时停下检查，不自动反复付费。第一份通过后，再依次扩展到 ANF、NYAX、PLAB。

| 案例 | 首要核对点 |
|---|---|
| GTLB | basic EPS 与 diluted EPS 分开；实际与下一季度指引分开；ARR 等新指标需原文支持 |
| ANF | $4.17 报告 EPS 与 $1.75 退款每股影响分开；不擅自做减法就标记调整后 EPS |
| NYAX | IPS 的预计收入不归到 NYAX 已实现收入；买方与标的公司不混淆 |
| PLAB | GAAP/non-GAAP、当季实际/下季指引分开；保留金额单位及期间 |
| AFRM | 正文缺口继续保留，不参与付费提取，不用截图替代来源 |

对每条模型提案分别记录：原文数字是否正确、期间、主体、单位、会计口径、引用、特殊项目处理，以及关键事实是否漏提。引用校验通过不算人工语义审核通过。同步报告请求状态、真实 token 用量、估计费用、预算预留和延迟。

四份公告仅用于验证接口和具体财务陷阱，不能代表长期准确率、选股胜率或完整复刻对方系统。催化评级、同时间盘前量比、开盘触发与 Discord 投递仍分别验收。
