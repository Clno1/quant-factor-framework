# 板块轮动 V2：真实数据验证与上线门槛

日期：2026-09-09。实现基础为当前主框架 `39e2236`，保留既有多因子、模拟盘、数据底座及运维改动。本文把代码正确性、外部复刻准确性和投资有效性分别记录。

## 1. 当前结论

**可以作为研究观察工具验收，不批准作为已验证策略或自动选股/仓位依据。**

- 用户没有 TradingView 导出数据。公开版目前只有规则级复刻与本项目冻结输入重放，不是作者数值对账。
- 真实 ETF 回看已经执行，结果不支持“复杂状态/积分一定比简单动量好”。没有按本次结果更改阈值、挑选最好周期或优化参数。
- SMH 已完成真实当前持仓广度试验，但持仓生效日未披露；这项测量不进入生产优先级，也不倒填历史。
- 生产总分和金额代理仍关闭，宏观背景未接入时留空。股票候选只读关联既有突破扫描。

## 2. 历史验证设计

程序：`scripts/research_group_rotation.py`；纯研究逻辑：`src/group_analytics/rotation/validation.py`。研究产物与正式快照目录分离。

研究目录：`outputs/group_analytics/research/validation_20260909_v1/`。`plan.json` 在下载前冻结规则代码 SHA256、参数、主题名单、日期切分及成本；`inputs.json` 冻结19个行情文件的哈希。恢复运行拒绝代码或已冻结输入变化，须另开研究版本。`labels.parquet` 保存逐主题收益标签，`report.json` 保存全部统计及逐期组合。

### 数据与样本

- 数据：FMP dividend-adjusted OHLC，2019-01-01 至2026-09-08，每个ETF 1,931根日线；包含17只原生ETF与SPY/QQQ两个基准。
- 科技：SMH、IGV、SKYY、CIBR、BOTZ、AIQ，相对QQQ。全市场：11只行业SPDR ETF，相对SPY。两组分别比较，不混排。
- 2019年为指标预热；2020–2022开发区间、2023–2024验证区间、2025以后回看留出区间。标签跨区间边界则剔除。合计1,664个可评价信号日期。
- **这不是严格未知样本外验证**：研究在2026年才冻结，ETF名单和规则可能已受既往市场影响；当前复权历史也不是逐日vintage。使用原生ETF避免当前成分回填，但不消除主题选择偏差。

### 信号与标签

比较前一日涨幅、RS20、RS60、两者均值、来源兼容积分，以及生产价格状态过滤后按RS20排序。所有计算只使用信号日及之前的完整收盘数据。

标签：信号日 T，**T+1复权开盘价到T+h复权收盘价**，h=5/20交易日；基准使用完全相同时间窗。这里是供应商复权价收益测量，不是名义成交报价。未来中间日缺失/非正价格、入场开盘缺失或61点信号历史不足均剔除，不补价。

Rank IC 每日横截面计算；状态收益先按日期平均，再用交易日块自助法，避免把同日股票当独立样本。20日为主检验、5日为辅助；500次循环块抽样是探索性区间，未做多重检验调整。

### 组合比较

每20个交易日定一次组合，次日开盘入场、第20日收盘退出，因此持有区间不重叠。每组最多2只、每只50%；价格状态规则不够2只时剩余现金不计息。所有方法使用同一完整ETF样本日，不因某一方法缺失而单独挑日期。

成本0/10/25/50基点为每次投资部分的双边费用，买卖各一半；即使重复持有同一名字也退出后重买并收费。日内按收盘盯市记录回撤。基准也按同一进出时钟和成本核算，**不是完整连续买入持有SPY/QQQ**。缺失或跨区间剔除的交易期全部跳过，不跨缺口伪造年化。报告里的目标权重L1换手仅用于描述，不等于实际双边成交量。

## 3. 首轮实际结果

以下是2025年以来、25基点双边成本、相同20个独立20交易日期间的平均每期收益差：

| 范围 | 方法相对简单RS20 | 每20日平均增量 |
|---|---|---:|
| 全市场行业 | 来源兼容积分 | -0.65个百分点 |
| 全市场行业 | 生产价格状态筛选 | -0.45个百分点 |
| 科技ETF | 来源兼容积分 | -0.68个百分点 |
| 科技ETF | 生产价格状态筛选 | -2.57个百分点 |

20个独立期低于预设40期门槛，增量置信区间保持空值，状态 `INSUFFICIENT_INDEPENDENT_PERIODS`。不能把负的均值直接解释为“永久失效”，但更不能宣称已经证明有效。价格状态法可能留现金，收益差同时反映风险暴露变化，不是纯选股优劣；尚未风险匹配。

作为辅助观察：2025以后20日预测窗，科技ETF的RS20/RS60平均Rank IC约0.163/0.300，来源积分约0.176；全市场行业对应约-0.002/-0.090/-0.035。这些横截面结果与组合结果不是同一统计对象；样本小、主题选择偏差与多重检验意味着不可据此挑选“最优模型”上线。

全部回看区间、25基点成本下的同钟组合净值（起点1；81期）仅供审计：科技RS20=3.687、来源积分=3.370、价格状态=1.957、同钟QQQ=2.946；行业RS20=1.799、来源积分=1.649、价格状态=1.944、同钟SPY=2.144。科技三种方法最大日度回撤约-45.3%/-49.7%/-43.7%。这些不是实盘收益，也不是产品收益承诺。

最终研究门槛：`promotion=NOT_APPROVED`。保留当前页面的可解释研究功能，不把评分变成交易执行依据。

## 4. 真实ETF广度试验

程序：`scripts/observe_rotation_holdings.py`。当前仅做SMH试点，不声称17个ETF都完成接入。

FMP的正式接口是 `/stable/etf/holdings`，供应商说明它提供持仓、权重等数据，但不能据此假定每条记录有历史生效日。[FMP ETF数据说明](https://site.financialmodelingprep.com/datasets/etf-mutual-funds)

本次响应有`updatedAt`，没有明确持仓生效日。保存首次观测时间、原始更新时间字符串、证券标识和响应哈希；不会把更新时间（时区也未明确）改名成持仓日期。无持仓生效日一律 `OBSERVATION_ONLY_NO_PROVIDER_DATE`、`point_in_time=false`。

- 首次观测：2026-09-09 04:28:38 UTC；价格截至2026-09-08完整收盘。
- 25只可映射股票，覆盖25/25，合计权重约99.9135%；剩余现金/未解析条目单独保留，不偷偷消失。
- 每只股票自身20交易日均价；必须20根连续有效价格。等权站线比例 **48.00%**；按可计算成员权重加权 **67.85%**。
- `measurement_complete=true` 仅说明本次成员行情覆盖合格；`production_eligible=false` 明确表示不能进入生产确认。

生产接入仍需：可验证持仓生效日/发布时间、首次可获得时间、完整证券映射、许可与历史快照策略。其他ETF还可能有海外上市和不同交易日历，不能按名字直接拼接美股交易日。

## 5. 工程验证与部署约束

- 真实日线正式构建：2026-09-08，22/22主题有效。冻结输入重放 `MATCH`；这是内部一致性检查，不是TradingView外部对账。
- 与SG对齐pandas3.0.5后，全量1,024项、59个子测试通过、8项跳过；单次验收发送另外3项测试通过。最初本地pandas2.2的4项失败属于当前主框架依赖行为差异；没有为掩盖这些差异修改核心数据代码。
- SG仍用root，保留13:15轮动timer、美东09:20双频道投递、宽基数据锁、550M内存上限及100%单核配额。禁止恢复已归档的旧US日更timer。
- 仅轮动writer替换升级，不改多因子、模拟盘、突破规则或交易授权。部署应逐文件核验基线并保留SG上的其他任务改动。
- 验收发送默认只预览；用户已授权验证后一次真实板块频道验收。独立receipt记录、无角色提醒、禁自动重试，不操作日常outbox。

部署实测记录在执行完成后补充；上述工程检查不构成策略有效性认定。

## 6. 后续准入

4. 若研究新规则，应单独版本化，增加风险匹配、稳健性和成本检验。宏观背景需在无背景基线之上验证增量，不为了贴合截图先凑分数。
