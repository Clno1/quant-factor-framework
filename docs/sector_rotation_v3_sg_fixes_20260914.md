### 为什么适配器不在 group_analytics 内？

仓库已有隔离测试禁止板块领域直接 import `src.breakouts`。跨域组合属于现有 `premarket_digest` 集成层，因此将此适配器放在那里，而非放宽测试或让核心模块反向依赖板块。

`src/breakouts/`、`src/data/`、`src/premarket_digest/momentum.py` 均未修改。旧双频道 prepare 的默认动量加载路径没有被偷偷替换；其独立容量与并行运行仍需上线窗口核验。

## 2. ETF 持仓与运行状态

修复 `holdings.py` 和 `observe_rotation_holdings.py`：

- 按已验证的供应商字段识别现金/外汇、应收应付、货币基金和部分期货证据；未知项目保留为未解析，不猜成股票。
- 多条空代码可作为不同排除条目保留，不再被误判成重复证券。

- 未解析或身份冲突的正权重保留为 excluded，不归一化冒充全基金覆盖。
- 归一化版本 `holdings-identity-v2`；指纹增加归一化成员、排除项与身份绑定。独立旧研究调用保留 `PROVIDER_ONLY_LEGACY` 标签，正式采集不走此兼容路径。

## 3. 热力图数据契约

新增 `rotation/reference.py`、`rotation/capitalization.py`、`scripts/refresh_rotation_reference.py`：

- 用 `is_current_coverage` 正确过滤当前证券，应用同版本证券不可用名单。
- 绑定 coverage 的 Security Master generation/hash，以 security_id 关联独立分类表；按有效期和知识日期筛选。
- 当前市值从已有 FMP company-screener 适配器单独采集，只写 `data/reference/group_analytics/rotation/capitalization/`。
- 与冻结的当前 ticker、交易所和 security_id 对齐，记录采集时间、来源、源数据哈希和缺失覆盖。
- 不宣称市值为某天精确收盘市值；`provider_effective_at=None`，只作当前非 PIT 观察。
- 内容寻址文件 + 原子 latest；覆盖版本变化或更早采集结果不能覆盖新参考。
- 展示要求同一 coverage 版本/收盘日、绑定身份代次、校验和正确、采集不在未来且不超过 72 小时。
- 市值缺失或过期返回明确不可用；全空不再返回 available；UI 显示采集时间及缺失数量。
- 历史快照仍禁止此热力图，市值不会进入多因子、回测或轮动评分。

price root/普通 unit 增加一个 **限时 120 秒、失败不阻塞价格结果**的 `ExecStartPost`，执行参考采集。新脚本必须随 unit 一起部署，不能只替换 Python 页面。
